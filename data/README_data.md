# Real-data source

The real-data application uses the publicly available anonymized diabetic macular oedema dataset:

Fu DJ, Kern C, Keane PA. *Anti-vegf therapy in diabetic macular oedema patients over four years* [dataset]. Dryad. 2020.

DOI: **10.5061/dryad.pzgmsbcfw**

Exact source file used:
`200319_DMO_report1_anonymised.csv`

## Local placement
Download the exact file from Dryad and place it locally at:

`data/raw/200319_DMO_report1_anonymised.csv`

The `data/raw/` directory is ignored by Git. The dataset must not be committed to this repository.
